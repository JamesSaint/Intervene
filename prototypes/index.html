Homepage prototypes

Four standalone sketches, two for each of the two sections under review. They are not part of the site build. Each is designed separately for desktop and for a phone, so view both.

Intervention experience

Prototype AThe raceA full-bleed scene. The response and the window run on one time axis; the stage in progress is set at display size and gives way to the outcome. Diagnostics sit in a drawer beneath. On a phone, time runs downwards. Prototype BThe dialOne object beside the headline. A single revolution of the face is the window; the four stages run round it, and anything past twelve o'clock is drawn on an inner lap in red.

Assessment evidence

Prototype CThe traceRecords, stage findings and the conclusion as one connected map. Every line is a dependency; a stage with no record is drawn as an empty socket. On a phone it becomes one rail read downwards. Prototype DAgainst the windowThe conclusion at display size over one logarithmic time axis. Each stage is placed against the six-hour window on its own, with its records beside it.
